## Sockrocket v0.1.18

- Add a single node from its share link in Merlin. Hysteria2 manual entry and subscription imports now preserve more connection settings, including SNI, ALPN, obfuscation and port hopping. The client can retry another configured ALPN when authentication fails.
- Show how many entries were skipped when importing a mixed subscription. A partial refresh keeps existing nodes that could not be matched. The Merlin and Mihomo comparison covers configuration import for all nine supported protocols.
- Fix the “paste first” error when adding domain routing rules. Rule-list downloads and previews now accept up to 2 MiB and 32,768 entries, including IPv4 and IPv6 CIDRs. The preview reports unsupported entries before saving.
- Transfer large rule changes through Merlin Software Center in chunks. The editor checks for concurrent changes before applying an update.
