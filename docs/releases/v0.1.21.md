## Sockrocket v0.1.21

- Import nodes from Clash, sing-box and Shadowrocket configuration files in the Merlin node manager.
- Preserve ECH settings on supported AnyTLS, Hysteria2 and VMess connections.
- Use the subscription's configured resolver for node hostnames during connection tests and proxy connections. Reimporting the full profile can update matching nodes in place while preserving group and rule references.
- Show the reason for failed latency tests in the Merlin node list.
