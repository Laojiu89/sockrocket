## Sockrocket v0.1.19

- Configure HTTP, SOCKS5, Mixed, and Shadowsocks TCP listeners from the Nodes page in Merlin. Each listener can connect directly or use the active proxy node. HTTP, SOCKS5, and Mixed listeners support optional username and password authentication.
- Proxy listeners follow the active node after automatic failover. Direct listener traffic is counted separately from proxy node traffic.
- Change a listener between a wildcard address and a LAN address on the same port. If the new address cannot be bound, Sockrocket attempts to restore the previous listener.
- Enable replay protection for Shadowsocks listeners and preserve it across configuration reloads.
