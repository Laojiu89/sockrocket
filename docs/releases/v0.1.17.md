## Sockrocket v0.1.17

- Download the saved Merlin YAML configuration from Advanced Settings, including routing rules, nodes, subscriptions, and credentials.
- Open a UTF-8 Sockrocket YAML backup in the editor, review it, and select Validate and Save to replace the router configuration.
- Transfer larger configuration saves in chunks through Software Center. Incomplete uploads and stale revisions leave the saved configuration intact.
